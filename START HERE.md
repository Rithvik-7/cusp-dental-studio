# Cusp Dental Studio

This folder contains the complete editable source and images for the current dental website, saved on 14 September 2026. The later redesign was cancelled before source changes were made.

Double-click **Open Website.url** to open the deployed private site in your browser. Sign in with the owner's account if prompted.

To edit and run the website locally, install Node.js 22.13 or newer, open a terminal in this folder, and run:

```sh
npm ci
npm run dev
```

Open the local address printed in the terminal. The page is in `app/page.tsx`, styles are in `app/globals.css`, and artwork is in `public/`.

This is a fictional clinic demo. The contact form previews a submission and does not send information or book real appointments.

Dependencies, generated build output, caches, and Git history were omitted to keep this copy portable. The source and lockfile are included.
